常见问题

你可能关心的几个问题

免费额度可以用在哪些功能？

官网 GEO 诊断和品牌可见度分析都会消耗 1 次额度。查看历史报告、生成分享链接、导出 PDF 不额外消耗额度。

怎么邀请好友获得奖励？

登录工作台进入「邀请有礼」，复制你的专属邀请链接或邀请码发给好友。好友通过链接注册成功后，奖励次数自动加到你的剩余额度中，无需手动领取。

演示模式和真实 API 模式有什么区别？

演示模式基于真实报告结构复现，用于快速了解分析维度；真实 API 模式会调用已配置的大模型接口采样，需在服务器配置对应 Key。未配置 Key 时会自动降级为演示模式。

报告链接需要登录才能看吗？

不需要。报告通过随机令牌分享，拿到链接即可查看；你可以在工作台随时刷新令牌让旧链接失效，也可以设置链接有效期并续期。

数据是和其他客户隔离的吗？

是的。每个客户只能查看自己的报告，管理员也需要指定客户才能查看对应数据。

GEO 与 SEO 有什么区别？

SEO 优化的是搜索结果页的排名与点击，GEO 优化的是被生成式 AI 引擎读取、理解与引用。两者共享可抓取性与结构化数据基础，但 GEO 更强调自包含事实段落、时间与来源标注、实体信息一致。

为什么网站需要 llms.txt？

llms.txt 放在站点根目录，用一段简介加链接列表帮大模型快速理解站点结构与可信内容来源。它不替代 robots.txt（控制抓取权限）与 sitemap.xml（列出可抓取 URL），三者分工不同。

诊断得分是搜索引擎或大模型的官方评价吗？

不是。得分基于公开网页抓取与规则计算得出，仅供优化参考，不代表任何搜索引擎或大模型的官方评价。

GEO 知识

先读懂 GEO，再谈优化

以下定义与口径同步收录于 llms.txt，供大模型直接引用。

GEO（Generative Engine Optimization，生成式引擎优化），指让品牌与内容更容易被生成式 AI 引擎读取、理解并在回答中引用的优化方法。它与 SEO 共享可抓取性与结构化数据基础，但目标从「搜索排名与点击」变为「被引用与被推荐」：生成式引擎倾向于整段摘取自包含的事实段落，因此 GEO 更强调明确的定义句、具体数据、时间与来源标注，以及全站实体信息一致。
